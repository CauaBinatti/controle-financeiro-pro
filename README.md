# 💰 Finanças Pro — Sistema de Controle Financeiro

Aplicação web desenvolvida para gerenciamento de receitas e despesas pessoais, com cálculo automático de balanço e persistência de dados no navegador.

## 🚀 Funcionalidades
- Cadastro de entradas (valores positivos) e saídas (valores negativos).
- Cálculo dinâmico de Entradas, Saídas e Saldo Total.
- Armazenamento automático via `LocalStorage` (os dados não somem ao atualizar a página).
- Interface responsiva e intuitiva.

## 🛠️ Tecnologias Utilizadas
- HTML5 Semântico
- CSS3 (Grid Layout & Variáveis CSS)
- JavaScript ES6+

## ▶️ Como Executar ou Visualizar o Projeto
1. Baixe ou clone este repositório para o seu computador.
2. Abra a pasta do projeto (`controle-financeiro-pro`).
3. Dê um duplo clique no arquivo **`index.html`** para abri-lo diretamente em qualquer navegador web (Chrome, Edge, Firefox, etc.). Não é necessária nenhuma instalação adicional.
